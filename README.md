1. Настроены зависимости для тестирования
  Добавлены библиотеки JUnit для модульных тестов
  Добавлена библиотека kotlinx-coroutines-test для тестирования корутин
  Добавлена библиотека MockK для создания моков (опционально)
2. Созданы фейковые классы для изоляции тестов
  Реализован FakeTaskRepository — упрощённая версия репозитория, которая хранит данные в памяти вместо реальной базы данных
  Это позволяет тестировать UseCase и ViewModel без подключения к Room или сетевым запросам
3. Написаны модульные тесты для UseCase
  GetTasksUseCaseTest — проверяет, что получение списка задач работает корректно (возвращает задачи при их наличии и пустой список, когда задач нет)
  AddTaskUseCaseTest — проверяет добавление задач и валидацию данных (например, отказ добавлять задачу с пустым заголовком)
4. Написаны тесты для репозитория
  InMemoryTaskRepositoryImplTest — проверяет основные операции репозитория: добавление, получение, удаление и обновление задач
5. Написаны тесты для ViewModel
  TasksViewModelTest — проверяет, что ViewModel корректно изменяет своё состояние при загрузке данных, добавлении задач и обработке ошибок
6. Написаны тесты для маппера
  TaskMapperTest — проверяет корректность преобразования между Entity и Domain-моделями
